# Never Stop 实时运行输出

用户在独立 Demo 交付后要求显示实时 Claude Code 执行过程。本次在现有分支加入默认展开、可收起的项目输出面板，同时支持 Codex。

1. 从 CLI JSONL 的公开回复、工具调用、工具结果和错误字段解析显示内容，不显示模型内部推理、系统指令或完整协议包。
2. worker 每 100 毫秒最多发送一个有界批次，控制事件仍独立传递。运行器向应用发出按项目划分的 output 事件；只保存在有界内存，不写普通日志或项目元数据。
3. 主进程再次隐藏资源凭据；每项目最多 300 项或 256 KiB，全局最多 4 MiB。UI 使用增量游标只拉取当前展开的项目，支持自动滚动、复制及清空显示。
4. 通过假 CLI 验证调用未结束时已经显示内容、高频输出不影响暂停、项目隔离和秘密脱敏；通过实际 Electron UI 验证显示和交互，再更新独立可执行包。
