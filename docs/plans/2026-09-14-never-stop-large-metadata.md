# 修复大进度文件阻止目录切换

目录迁移复用了用于界面读取的 1 MiB 限制，因此已有大 progress.md 的目标目录也无法选用。迁移操作需要保持文件完整，与界面展示上限分开。

- 对迁移元数据使用分块摘要与文件大小比较，缺失文件通过排他复制完整迁移，不读取整文件到内存。保留同名不同内容冲突规则。
- 大 progress.md 不能阻止读取有效的结构化进度，也不能被短摘要覆盖截断。界面给出有界提示并保留磁盘原文件；界面目标编辑上限不变。
- 使用与失败案例相同字节数的合成数据复现，验证既有目标文件、源文件复制、相同文件、冲突及打包界面迁移。实际项目文件只读检查大小，不自动切换用户任务。
