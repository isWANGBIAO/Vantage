# Markdown 结构一致性修复

范围：#87、#135、#136。只处理源码、合成测试，不读取私人提示词或部署。

## 设计与任务

1. 用合成 Markdown 复现围栏示例误计入进度、GFM 合法任务标记遗漏、前后端全局压缩空白破坏嵌套列表和代码。
2. 增加轻量 Markdown 围栏扫描器，按围栏字符和长度识别开闭，保留 literal 区；项目进度不统计其中内容。
3. 任务标记支持 dash/star/plus、有序列表和合法空白；原来的项目分组规则保持不变。
4. 前后端清洗仅对非代码行执行既有损坏标记修复，不全局压缩空白；保留代码块空行、首尾缩进和 Markdown 硬换行。
5. 运行新增回归、现有 sanitizer/项目/发布测试、全 Python 和前端检查；独立规格/质量审查后 draft PR，CI 通过再合并。
