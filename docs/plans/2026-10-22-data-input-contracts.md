# 数据输入、完整请求预算和跨日发布合同

范围：#58、#69、#70、#88、#89、#90、#91、#131、#137。基于财务 PR #144，保留 AI 流 PR #143 的独立修改，不在本批重写流协议。

- Excel 每次复制使用原子预留的唯一目标；复制阶段为 .copying，避免旧源文件 mtime 被清理器误判。更新时刻后原子发布为 .xlsx。原文件始终不修改。
- 单条保留记录仍进入 Current Day；非有限数字变 null；混合 ISO 日期逐元素解析；时长解析支持小数和仅分钟，非法负时长不反转为正值。
- 最终拼接提示词重新核算全部内容。必要提示词/汇总无法容纳时，明确失败，不静默删除必需数据，也不调用 provider。
- 第一轮开始前为第二轮模板、近期数据及第一轮回复上限预留；每一轮发送前重新核算全 messages，包括上一轮完整回复。
- 输入日期与生成完成日期不同则失败，任何计划/context 写入前保留旧结果，不能把昨日输入标成今日计划。
- 农历节日枚举覆盖公历年前后的农历年；除夕严格是下一次春节前一天，不猜腊月29/30。

验证采用真实临时 xlsx、受控 provider、本机复制和回入清理器、冻结跨午夜时钟。初始9个边界失败、预算2项失败、跨午夜1项失败均有红绿证据。独立审查额外发现复制过程中旧mtime与janitor竞争；专项回归先失败再通过。

完整验证以当前 PR CI 与台账为准。正常完成/异常路径清理 staging；进程被系统强杀时仍可能留下 .copying，现有只清理 .xlsx 的维护任务不会清它。该孤儿文件不被当有效快照使用；未来如增加回收，必须验证活跃所有权，不能按源mtime删除。
