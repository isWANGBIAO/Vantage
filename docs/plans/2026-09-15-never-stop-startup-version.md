# 升级后的自启动入口同步

旧版只在保存设置时更新 Windows 自启动项，便携 EXE 名称随版本变化后，自启动仍可能指向旧版本。应用启动时应读取原设置并同步已启用的入口，使下一次登录运行当前版本。

- 使用稳定的应用自启动名称，优先指向便携 EXE 而非解压临时目录。保留用户在应用与系统中的禁用选择。
- 仅正式打包版本自动同步；隔离数据的测试实例不能改生产自启动项。同步失败显示错误但不阻止项目恢复。
- 页面显示实际应用版本。项目数据目录保持不变，升级不清除目标或累计时间。
- 用隔离的 Windows 自启动项验证从旧路径更新到新路径、关闭与失败行为，保留现有运行与桌面回归。此功能不宣称联网发现、下载或安装更新。
