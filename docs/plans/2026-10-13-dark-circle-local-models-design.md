# 黑眼圈本地可选模型设计

用户已确认：ONNX 默认、SAM3 可选；模型和额外环境不捆绑、不自动下载，复用已有本地环境。采样采用眉毛下缘到眼睛上缘的中位距离，按该半径扩张真实眼睛轮廓，仅保留下眼睑以下皮肤。双眼、双眉缺失或质量不合格时跳过，无固定椭圆兜底。脸颊参考必须不与眼下区域重叠；结果为相对外观指标，不是医学严重程度。

## 架构

- 主后端和 Electron 不导入 ONNX Runtime、PyTorch、Transformers。长期本地分析子进程由配置的 Python 启动，串行处理请求，失败有界超时、重启，stdio 使用本地 JSON 协议。外部环境不下载或安装任何内容。
- settings.json 保存 face_analysis_method、face_analysis_python、face_analysis_onnx_model、face_analysis_sam3_model_dir。公开默认值没有机器路径。UI 显示缺失环境提示及可编辑路径。
- 共享 ROI 与评分代码，ONNX 使用 BiSeNet ImageNet 预处理，CPU provider；SAM3 使用已有本地模型，离线 face/eye/eyebrow 提示与共享视觉嵌入。
- 每个方法/模型版本配置独立历史目录和数据库，旧数据库原样保留。报告注明方法、算法版本、跳过原因；覆盖图展示眼下和脸颊。生成图片仅通过受约束的资产路由访问。
- 不加入新医学 AI，不尝试消除全部光照误差；缺失环境和失败不能变成假分数。

## 验收

单元测试覆盖有效与缺失眼/眉、非重叠参考、曝光/姿态拒绝、设置持久化、隔离历史、子进程错误/超时与包资源排除。用本机已有模型在已有照片做有限真实验收。运行相关与完整 Python/frontend 检查，再 RUN.bat 自然完成构建安装启动；复查安装版版本、设置与报告。
