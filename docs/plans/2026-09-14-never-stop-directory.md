# Never Stop 更改项目目录

项目页允许选择并更改已有项目的工作文件夹。保留项目 ID、累计运行时间、名称、已发布目标和资源选择；累计时间仍存在应用数据目录，不依赖项目路径。

1. 验证新路径存在且是目录，并拒绝占用其他项目的目录。暂停旧执行并确认进程树结束，再迁移和保存新路径。原来运行的项目成功后继续，暂停项目保持暂停；失败保留旧路径并暂停。
2. 对目标草稿、进度 Markdown 和进度 JSON 预检冲突，仅复制新目录缺失的文件。已有不同内容不覆盖，源文件不删除。保留软件进度缓存；旧目录已经搬走时使用新目录文件，缺少目标文件可从已发布目标恢复。
3. 清除旧 CLI 会话关联，在新目录建立新会话，保留目标但不声称迁移旧会话的聊天上下文。此操作不搬运源码和其他项目文件。
4. 界面显示旧、新路径及操作说明。按路径隔离草稿与进度状态，避免旧目录异步响应覆盖新目录。
5. 验证运行/暂停切换、累计值保留、进程 cwd、新会话、并发路径占用、迁移冲突、旧路径失效及实际打包 UI。独立版本为 1.0.76。
