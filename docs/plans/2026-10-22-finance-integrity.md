# 财务数据含义与日期一致性修复

范围：开放 issue #54、#55、#66、#71、#111、#126、#127、#128、#129。使用合成数据，不读取或修改私人财务文件，不部署。

## 设计

- 有语义日期时，指标取最新有效日期，而不是 Excel 物理末行；没有日期的表保留末个有效金额语义。纯数值金额不得被猜为 epoch 日期。
- 实际摘要始终只使用实际行，包括实际行集合为空的情况。预测余额先按解析后的日期排序，再累计；API 与绘图保持一致。
- 金额解析保留科学计数法、Unicode 负号和会计括号；接受明确货币前后缀与千位分组，拒绝混杂文本和非有限数值。Python 与前端合同一致。
- 先识别完整汇总行，再识别部分标签，避免流动负债抢占负债合计。
- 预算识别同时支持“非必需/不必需”；后端返回实际预算月份天数，前端日预算转换使用该天数。
- 前端接受合法 null budget；全部金额未知的集合总额仍是未知，真实零保持零。
