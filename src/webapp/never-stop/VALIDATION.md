## 未测和明确限制

- 没有重启或注销用户当前电脑；实测的是后台进程崩溃/重开，登录自启配置与系统关机事件路径已实现，但真实开机恢复需在后续使用中核验。
- 没有验证 macOS / Linux 实机。Linux 登录自启暂不支持；非 Windows 锁恢复和进程中断实现未列为已通过。
- Windows CLI 目前要求原生 `.exe`，不执行 npm `.cmd` shim。
- 没有实测复杂远端环境、代理跳板或长期脱离 SSH 的作业。SSH 配置导入会展示不支持选项。
- 真实 CLI 接入验证证明新建与续接能调用，不是“求解器提速 30%”等业务成果验证。Demo 不判断用户项目是否达标。
- 构建仍有单个 JavaScript chunk 大于默认提示阈值的提示；图表已按需导入，页面包约 831 kB（gzip 273 kB）。首版检查的原有开发工具依赖审计有 7 条提示，生产依赖审计为 0；本次未无关升级原有构建工具链。
